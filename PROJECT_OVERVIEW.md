# PROJECT_OVERVIEW.md

## Цель проекта
Модульная Android-песочница **SandboxForge** на Kotlin (+ компактный C++ NDK на следующих этапах) со сборкой APK через GitHub Actions:
- 3 типа контейнеров: Чистый, Общий, Приватный/Выборочный.
- 3 способа установки: клиент Google Play, установка из APK, импорт с телефона (плюс перенос сохранений и клонирование).
- Гибридный запуск («мясо с гарниром»): Мод-контейнер на базе прослойки `SandboxShim` (время/скорость/память/модули/файлы) + Чистый профиль через Shizuku для банков и жёсткого анти-тампера, с автодетектором движка и ручным переключением.
- Плавающая панель инструментов, сканер памяти (уровень GameGuardian/Cheat Engine) и однофайловые модули расширения с межмодульными вызовами.

## Текущее состояние («велосипед v0.2» — Шаг 2.1 выполнен)
- **Шаг 1 проверен** на реальном OnePlus PYB110 (Android 17 / API 37, ColorOS с встроенным Tango 32-bit).
- **UI-полировка:** добавлены реальные иконки приложений (кэш `meta/icons/*.png`, отображение в списке устройства и в контейнере) и повышена контрастность тёмной темы.
- **Автодетектор движка (`EngineAdvisor`) + ручной переключатель:** анализирует пакет и `.so` на признаки банков/анти-тампера и предлагает `SHIM` или `Чистый`, с ручным переключением на карточке.
- **Первый рабочий движок клонирования и прослойки (`SandboxShim`):**
  - Выделенный pure-Java модуль `:shim` (~6 КБ `sandbox_shim.dex`, без сторонних зависимостей и конфликтов) автоматически собирается в `assets/` на GitHub Actions.
  - Бинарный патчер `AndroidManifest.xml` (ARSCLib) для `base.apk` и всех `split_*.apk`: разворачивает относительные имена классов до смены `package`, удаляет `sharedUserId`, переписывает `authorities` и кастомные `permission`, внедряет `SandboxAppComponentFactory` (с делегированием оригинальной фабрике) и `SandboxShimInitProvider`, опционально скрывает иконку клона с рабочего стола.
  - 16 КБ выравнивание `.so` и 4-байтовое выравнивание `resources.arsc` (`ApkZipAligner`) + локальный RSA-2048 ключ устройства + подпись APK v1/v2/v3 (`apksig`).
  - Установка одиночных и Split APK через единую `PackageInstaller.Session`, запуск клона из SandboxForge и обратная телеметрия `[ShimBridge]` прямо в окно логов.

## Утверждённые решения
- Выбран **Вариант 1** (Прослойка-инжектор `SandboxShim` + отдельный Чистый профиль для банков через Shizuku) с портативностью на любое Android-устройство.
- Стек: Kotlin (Jetpack Compose, Material 3, SDK 26–35) + pure-Java `:shim` + минимальный C++ NDK на следующих этапах.
