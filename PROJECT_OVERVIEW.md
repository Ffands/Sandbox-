# PROJECT_OVERVIEW.md

## Цель проекта
Модульная Android-песочница **SandboxForge** на Kotlin (+ компактный C++ NDK на следующих этапах) со сборкой APK через GitHub Actions:
- 3 типа контейнеров: Чистый, Общий, Приватный/Выборочный.
- 3 способа установки: клиент Google Play, установка из APK, импорт с телефона (плюс перенос сохранений и клонирование).
- Настройки контейнера: системное и сетевое время (± смещение, заморозка при выходе или фоновый ход), скорость (ускорение/замедление/пауза), профиль устройства, выбор microG / системные GMS.
- Плавающая панель инструментов, сканер памяти (уровень GameGuardian/Cheat Engine) и однофайловые модули расширения с межмодульными вызовами.

## Текущее состояние («велосипед v0.1» — Шаг 1 выполнен)
Реализован минимальный чистый Android-проект на Kotlin + Jetpack Compose + GitHub Actions CI:
- **Один контейнер (`default`):** изолированная структура папок (`apks/`, `data/`, `sdcard/`, `meta/apps.json`).
- **Импорт с телефона:** список установленных приложений с поиском, фильтром системных приложений и корректным копированием `base.apk` + всех `split_*.apk` (с выставлением `read-only` для Android 14+).
- **Установка из APK:** выбор `.apk` через системный проводник (SAF), валидация архива, определение нативных ABI (`arm64-v8a`, `armeabi-v7a`) и сохранение в контейнер.
- **Файловый менеджер контейнера:** строго изолирован в корне контейнера, навигация, создание папок, безопасный текстовый предпросмотр (до 128 КБ), экспорт файлов наружу, импорт файлов внутрь, удаление.
- **Окно логов и краш-логгер (`AppLogger`):** живой просмотр событий, фильтрация по уровням, копирование в буфер обмена одной кнопкой, сохранение лога в файл, автоматическая запись сессии на диск (`filesDir/logs/session_*.log`) и синхронная запись краш-дампа (`last_crash.log`) при падении с баннером восстановления при следующем запуске.
- **Инспектор / точка подключения рантайма (`ContainerRuntime`):** интерфейс и диагностическая заглушка, проверяющая сплиты, ABI и права `read-only` до подключения виртуального движка.
- **GitHub Actions CI:** автоматический запуск unit-тестов и сборка `app-debug.apk` с выгрузкой в Artifacts.

## Утверждённые решения
- Стек: Kotlin (Jetpack Compose, Material 3, SDK 26–35) + минимальный C++ NDK (начиная со следующих этапов).
- Режим привилегий: гибрид user-space + Shizuku по мере необходимости.
- Сервисы Google: переключение microG / системные GMS на контейнер.
- Локальный Root внутри контейнера: отложен как опциональный тумблер (выключен по умолчанию).
- Подход Шага 1: Вариант 1 («крепкая рама + логи + импорт сплитов + файловый менеджер + CI»).

## Следующий маленький шаг
