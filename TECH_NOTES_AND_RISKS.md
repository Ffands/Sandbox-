# TECH_NOTES_AND_RISKS.md

## Архитектурные заметки Шага 1
- **Сборка без `gradle-wrapper.jar`:** workflow GitHub Actions использует `gradle/actions/setup-gradle@v4` с зафиксированной версией Gradle `8.10.2`, поэтому бинарный wrapper-jar в репозитории не требуется.
- **Split APKs:** импорт с телефона копирует `sourceDir` (`base.apk`) и весь массив `splitSourceDirs` (`split_*.apk`), сразу сохраняя список обнаруженных нативных ABI (`lib/<abi>/*.so`).
- **Android 14+ read-only DEX/APK:** все скопированные в `apks/<pkg>/` файлы помечаются `setReadOnly()`, а удаление корректно снимает флаг `writable` перед очисткой.
- **Изоляция файлового менеджера:** `ContainerFileManager` проверяет `canonicalPath` перед каждой операцией — выход за корень контейнера через `..` невозможен.
- **Краш-логгер (`AppLogger`):** `Thread.setDefaultUncaughtExceptionHandler` синхронно сбрасывает стектрейс через `FileOutputStream.fd.sync()` в `filesDir/logs/last_crash.log` до завершения процесса. Сессионные логи ротируются при >2 МБ и хранятся в количестве последних 10 файлов.
- **JVM unit-тесты `org.json`:** добавлена зависимость `testImplementation("org.json:json:20240303")`, чтобы тесты `ContainerStorage` не падали на пустых заглушках `android.jar`.

## Найденные слабые места и пограничные случаи (для следующих шагов)
1. **Внешние Split-архивы (`.apks` / `.xapk`):** на Шаге 1 установка из файла поддерживает одиночный `.apk`. Поддержку `.apks`/`.xapk` архивов добавим при расширении установщика.
2. **Тяжёлые приложения при импорте:** копирование игр размером 1–2 ГБ сейчас показывает индикатор прогресса без процентов; позже стоит добавить побайтовый прогресс и проверку свободного места на диске до старта копирования.
3. **Запуск гостевого APK (Шаг 2):** `DiagnosticStubRuntime` пока только инспектирует контейнер. Реальный запуск потребует user-space виртуализации (Binder/AMS/PMS-прокси + нативный IO-редирект) с учётом ограничений Android 14–15 (Hidden API, 16 KB page size).
4. **Google Play внутри контейнера:** нативный `com.android.vending` хрупок в user-space на Android 12–15; на этапе магазина стоит сравнить клиент протокола Play (модель Aurora Store) и проксирование GMS/microG.
5. **Сдвиг времени и TLS:** при реализации подмены времени обязательно изолировать проверку сроков действия TLS-сертификатов, иначе HTTPS сломается при сдвиге даты.
6. **Лог-файлы при краше в нативном C++ коде:** `UncaughtExceptionHandler` перехватывает только Java/Kotlin-исключения. Когда на следующих этапах появится C++ NDK, понадобится отдельный обработчик сигналов (`SIGSEGV` / `SIGABRT`), пишущий дамп в ту же папку `logs/`.
